# aulm-tripper-cosmic-dodge
AULM TRIPPER: COSMIC DODGE

AULM TRIPPER is a cosmic arcade game where you dodge obstacles, survive as long as possible, and aim for a higher score.

Features

- Fast-paced arcade gameplay
- Multiple obstacle types
- Different ships and trails
- Visual effects and animations
- Multiplayer support
- Score and progress saving
- Mobile-friendly controls

Android

An Android version is being worked on. The game is built using HTML, CSS and JavaScript.

How to Play

Open the game in a browser and use the on-screen controls to move your ship and avoid obstacles.
